Building a Simple CMS

October 15, 2026

I’ve been around content management systems (CMS) for a long time.

I wrote one for a project I did for UCSF researchers before Wordpress, Drupal, Squarespace or Wix existed. I wrote it in PHP. The researchers logged in, wrote their articles and then clicked a button to publish to the web. Seemed like magic at the time for non programmers to publish to the web.

After that, I worked for Pantheon. I sold a platform for developers building CMS systems based on Drupal and Wordpress. I joined as their first sales person. 10th employee and $0 in revenue. I left Pantheon having a successful run in sales and managing a sales team. I helped grow Pantheon from $0 to $50M in annual recurring revenue.

Today, I wanted to build a CMS again. But building software has been revolutionized in the past year.

The things that took me months to do when I built a CMS now I can do in half an hour.

So today I built jeffpflueger.com as front end of a simple CMS system using Google Docs.

How it works:

  1. I make or edit content entries in Google docs.
  2. I have an Apps Script that is now a button that lives next to every google doc that I write called Blog Publisher
  3. When I click the Publish the script commits the content to github (version control), converts it to HTML and publishes it on GitHub pages as a webpage

The amazing part of all of this, is that the world has moved on from OpenClaw being the defacto local AI agent that can orchestrate complex workflows like this.

I was using Claude Desktop. As Clause Desktop developed the code, there were still steps that I needed to complete (like granting permissions, pasting API Tokens, etc)

But Claude completed so much of the work by interacting with my browser (like creating a Apps Script, pasting the code into the web interface, testing, doing visual regression testing of the published web page to ensure that the output was what was intended, pushing and pulling from GitHub. Some of this I instructed Claude to do. Much of it, it did because it was the right thing to do without any instruction from me.

Just have to take a moment and reflect on how FAST the world is moving right now.

30 minutes. An entire simple Content management system that this post is written with.

Now let me click Publish.
